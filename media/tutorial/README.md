# Page Notes — tutorial assets

| Folder | What | Used by the site | In git |
|---|---|---|---|
| `recordings/` | Real recordings of the extension v1.3 (`<id>-main.mp4`, `<id>-popup.mp4`) + their timelines (`<id>.json`) | Yes — docs “How it works” playlist, blog, reel | Yes |
| `posters/` | Playlist thumbnails (`<id>.jpg`) | Yes — playlist list | Yes |
| `voice/` | Narration (male voice, en-US-ChristopherNeural) per video + timing JSON | Yes — playlist player | Yes |
| `music/` | Background music (original, synthesized — no license needed) | Yes — playlist player | Yes |
| `source-images/` | Source pictures used to build the recordings (the YouTube watch-page screenshot behind the “Streamly” site) | No | Yes |
| `youtube/` | Final 1080p YouTube videos: `with-voice/` (narration + music) and `music-only/`, + thumbnails + titles/descriptions/chapters | No | No (large) |
| `reels/` | Instagram / Shorts reel 9:16 + cover | No | No (large) |
| `gifs/` | 15–20 s GIFs for social posts / README / store | No | No (large) |

`youtube/`, `reels/` and `gifs/` are git-ignored (≈170 MB, not needed by the website). Keep a copy elsewhere
(e.g. Google Drive) or remove their lines from `.gitignore` to commit them.
Store images live in `public/extensions/store/`. Everything is regenerated by `scripts/extensions/page-notes-videos`.
