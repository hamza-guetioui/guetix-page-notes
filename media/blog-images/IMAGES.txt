Folder : public/blogs/page-notes-chrome-extension/
Topic  : Developer Tools
Colour : warm amber  #fbbf24   (the one accent colour for every image of this story)
Idea   : A dark portfolio website with yellow, pink and green sticky notes pinned on it and a small orange toolbar in the corner

EVERY STORY NEEDS 3 IMAGES
  1. COVER     — the website image (cards, article header, link previews)
  2. INSIDE    — the picture(s) shown inside the article text
  3. MAGAZINE  — portrait.png, the full page in the flip-through magazine

  [DONE]     3  portrait.png              MAGAZINE full-page opener
  [OPTIONAL] 3b cutout.png                MAGAZINE cover pop-out
  [AUTO]     glyph.gif / glyph-still.webp     generated animation — do NOT replace

HOW TO ADD
  1. Save the image in THIS folder with the exact file name above (PNG or JPG).
  2. Run:  node scripts/blog/optimize-images.mjs   (makes the small .webp)
  3. Run:  node scripts/blog/write-image-briefs.mjs (updates this STATUS)
  4. Rebuild / redeploy. Missing images are fine — the site falls back to
     the next image, then to the story's animated panel.

STYLE FOR THE COVER + MAGAZINE IMAGES
  Modern editorial magazine art direction (think WIRED / Kinfolk tech
  issue): one bold hero subject, strong graphic composition, lots of
  negative space, premium 3D render or photo-real, dramatic rim light,
  near-black background with warm amber (#fbbf24) as the single accent light
  colour, subtle film grain, crisp details, high contrast. NO text, NO
  letters, NO numbers, NO logos, NO UI labels, NO watermark.
